# Snoke

A Snake game I made at Scrapyard, with a few things changed to make it more annoying. It starts normally, then changes the rules as you collect apples.

## Play

Download the repo, open `index.html` in a browser, and press **Start Game**. Use a laptop or desktop and move with **WASD** or the **arrow keys**. Sound is part of the joke too.

## The levels

1. Normal Snake.
2. The controls reverse and the background starts changing colors.
3. The apple starts jumping around.
4. The controls switch to the apple while the snake chases it.

## Files

- [index.html](index.html) — page and game canvas
- [script.js](script.js) — game logic
- [style.css](style.css) — styling

Built with HTML, CSS, and JavaScript. No packages or build step needed.
